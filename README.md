### `Circle browser`

[![Downloads](https://img.shields.io/github/downloads/Circle-browser/desktop/total.svg)](https://github.com/Circle-browser/desktop/releases)
[![Crowdin](https://badges.crowdin.net/Circle-browser/localized.svg)](https://crowdin.com/project/Circle-browser)
[![Circle Release builds](https://github.com/Circle-browser/desktop/actions/workflows/build.yml/badge.svg?branch=stable)](https://github.com/Circle-browser/desktop/actions/workflows/build.yml)

Circle is a firefox-based browser with the aim of pushing your productivity to a new level!

> **Note:** Circle browser was forked and copied from the original [Zen Browser](https://github.com/zen-browser/desktop) project. We thank the Zen Browser creators for the amazing base!

### Contributing

If you'd like to report a bug, please do so on our [GitHub Issues page](https://github.com/Circle-browser/desktop/issues/) and for feature requests, you can use [GitHub Discussions](https://github.com/Circle-browser/desktop/discussions).

Circle is an open-source project, and we welcome contributions from the community! Please take a look at the [contribution guidelines](./docs/contribute.md) before getting started!
