# Security Policy

## Reporting a Vulnerability

Please report security vulnerabilities [here](https://github.com/Circle-browser/desktop/security/advisories/new).

> **Note:** Circle browser was forked and copied from the base of the Zen Browser project. If your security vulnerability applies to the underlying Zen Browser project or Firefox, please consider reporting it to them as well.
